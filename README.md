## 直接打开

双击 `dist/Money3.app`，或根目录 `启动Money3.command`，在窗口选择 SQLite 数据库。
安装包面向 **Apple Silicon / macOS 14+**，内含 Python 与 Qt，不需另外安装 Python。
Intel Mac 需重新构建；本地包尚未做 Developer ID 签名、公证或其他机器分发测试。

维护流程：Money3本目录交易流水修改【谁】→运行 `./启动Money3.command --excel` 入库→Money3 按 ⌘R 刷新。
Money3 不修改数据库、Excel、行情或券商账户，不下单、不上传资产。实时行情仅在启用后连接长桥，不同步或写入交易数据库。

## 计算边界

1. 核心为 Decimal/e8。人员权益与券商成交分账；撤销/参考不进有效持仓。
2. 起始日只裁切报表；计算成本保留此前历史。搜索匹配整组证券，避免丢失历史买入。
3. 拆股按日期和券商范围重放；OPENING 为开账截止点，REFERENCE 不新增入账。
4. 缺价格、成交粒度冲突、未知成本时保留缺失；不能把候选数量加倍确认为持仓。
5. 当前总资产仅股票市值；微操不叠加月收益。缺可靠现金期初/净额时不称为现金余额。
6. CNY 是 USD 结果按对应估值日折算，不含汇率损益。源库当日值优先；启用独立汇率缓存时，按下方“人民币汇率更新”的明确规则折算。完整跨币种会计与 ACCOUNTING 尚未开放。
7. 原微操先买后卖实际为最近买入优先、先卖后买为 FIFO，且有残额重复按原数量分摊的问题。本版保留配对顺序、采用精确原金额分摊，**部分微操结果明显不同**，差异未验收通过。
8. 旧程序会抹去部分极小残量；本版保留精确数量和负仓异常，因此清仓归类、成本和期间合计可能不同。详见决策及对账报告。
