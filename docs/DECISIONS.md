## 后续阶段决策与边界

- A19：旧源码 pending_buys[-1] 实为 LIFO；先卖后买用队首 FIFO。本版兼容此顺序，纯引擎也有 FIFO 测试，不混称二者。
- A20：旧程序将部分剩余 lot 金额再次除以原订单总数量，可能低估后续匹配成本。本版精确按原金额/数量分摊，不保留此缺陷；差异作为 M6 未通过项公开。内部不逐配对四舍五入到分，仍可能有展示级差异。
- A21：Money2 的 database_prices.write_price_frames 明确把 US 行情写成 SYMBOL.US。本版仅对 instruments.market='US' 使用此已证实适配；不按任意代码前缀猜市场。
- A22：复权未知不自动修复；明确复权价与拆股重放冲突时拒绝重复估值。缺历史日价不借 LATEST。
- A23：原 Excel 总览公式常无保存的数值缓存。18 KPI 对账从参考明细独立推导并标注，不用数据库值充当黄金值。
- A24：源数据的小数股/拆股可能产生极小正负残量。本版保留 Decimal，不沿用旧 0.005 股归零阈值，因此清仓归类、成本和合计仍有差异。
- A25：CNY 是 USD 结果按对应估值日折算，要求当日唯一汇率；不含汇率损益。账户现金不按人员权益比例分摊。
- A26：同订单多粒度、重复执行 ID 或缺可靠执行关联时，不静默去重。数量/成本/市值/微操不确认为有效结果，候选值保留在审计证据。
- A27：原始交易用于审计，完整16列计算见交易回放；报表支持本页/整份筛选导出。
- A28：偏好按源库路径散列隔离；缓存键含源库及WAL大小/修改时间、scope、版本，最多4份进程内结果。

### 2026-10-20 跨日快照与收盘基准
事实：本机缓存原先仅 latest_quotes(symbol,session)，源库收盘停在10/16；缓存仍有10/19盘中收盘附近的24只报价。旧临时日历行随着实时交易日切到10/20而消失；旧基准条件仅要求早于今日，可能错误沿用周五。
决定：独立缓存按纽约交易日归档每个时段最后报价，夜盘20点后归次交易日；不写源库。历史日期优先盘中快照，其次最后已保存报价；类型 ESTIMATE_CLOSE 和 CLOSE_ESTIMATE/PARTIAL_ESTIMATE 区分正式价与估值质量。只有盘中报价距离普通16:00/半日13:00收盘不超过120秒可作次日估值基准，绝不宣称官方收盘价。正式同证券同日 DAILY_CLOSE 优先。历史价格回放账本而非按今日持仓回填，以处理人员、渠道、买卖和清仓。若软件没有接收某天报价，不能凭空恢复；基准缺失保留未知。
