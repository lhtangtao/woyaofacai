# 行情监控中心 P0（Money3）

修改者：Codex（代码修改）。实现范围以用户提供的《Money Portfolio 行情监控与技术分析中心 PRD v1.0》P0为准。入口为 **AI 助手 → 行情监控中心**，既有页面编号不变，新页面编号21。

## 使用及只读边界

- 默认“仅本人持仓”，按启用人员中名称为“个人”的ID筛选；未找到时明确提示，绝不退回所有人。可切到“全部账户持仓（所有人）”，或选择渠道。
- 调用现有 `AnalyticsService.calculate()` 的“当前持仓”报表，只消费可信的正持仓数量。沿用既有撤销/参考排除、归属、划转、拆股、清仓和小于0.5股余股展示规则，不另算财务数量。独立的只读服务实例避免误用另一个数据源的可见报表或依赖旧行情缓存的迁移状态。
- 同一分析代码/市场合并为一行，保留各持仓原代码、账户、人员、数量、映射及持仓核对状态。本人/全员/渠道各有独立观察范围；日历日期改变不重建观察配置。
- 新增持仓自动补入，已清仓标为“已不再持有”，从该筛选项查看缓存历史；不自动删除用户映射或未来规则。当前列表的“查看/管理所选映射”可选来源证券，查看依据、倍数/方向及来源ID，确认手动覆盖或改看ETF自身。
- 原业务库、流水Excel、`engine/`、`domain/trade_time.py`不修改。财务收益不采用监控中心的正股价替代ETF价。
- 观察配置和缓存写到应用数据目录下独立的 `monitoring.sqlite3`；该文件名有保护检查，不能指定原财务数据库。每个工作任务打开自己的SQLite连接。

## 行情、缓存与线程

- 沿用原行情配置和 `create_context()`，支持项目当前统一配置及旧凭证加载方式；不另建登录界面。行情读取与SDK值转换复用 `_SDK_VALUES_LOCK`。观察价与财务估值字段分开。
- 原 `QuoteFeed` 开启时，把美股观察代码并入其集合，去重订阅，并复用其快照。监控服务本身不创建第二组订阅。原实时服务未运行或报价过旧时，后台pull报价最多每个代码一分钟一次；页面每10秒检查共享报价。首次日线获取按证券顺序执行，留有节流间隔。
- 日历使用长桥美股交易日与半日市，纽约时区自动处理夏令时。16:00/半日市13:00收盘后加15分钟确认缓冲；未完成日线不入库。SDK返回的naive时间按**系统本地时间**解释，再换算美东日期，不能直接附加UTC；报价持久化为有时区的UTC。
- 首次取最多500根前复权常规时段日K（含拆股/分红调整，以API为准），后续仅补完成交易日及10个日历日的重叠区。每个交易时段首次检查该小段复权历史，防止拆股生效日尚未收盘时价格尺度不一致；不是每10秒拉全量日线。
- 重叠K线发生变化时，整段500根重新获取并原子替换，避免混用复权尺度；过期报价不能沿用到新尺度中。均线及价格统一在现有调整尺度上比较。
- 日历/日线失败退避5分钟，报价失败至少间隔1分钟；不向页面或日志打印底层异常中的凭证。缓存保留并标记过期，展示报价时间、日K截止日及可重试信息，不把缺失值填零。
- 网络、持仓回放、SQLite和指标在原线程池的Worker执行；筛选/数据源变化取消旧任务，通过代数标记丢弃旧返回，退出取消当前监控任务。已发出的SDK请求不能强制中断，但不会阻塞UI线程。

## 技术计算定义

- MA5/10/20/50/60/120/200/250：最近N个**完成日**收盘价算术平均，不足N根为缺失。
- 偏离率：`(现价/MA - 1) × 100`；短/中/长分别对比MA20/50/200，±0.5%内为震荡，以上偏强、以下偏弱。缺均线则数据不足。
- RSI14：前14个相邻日价格变化的平均涨跌作为种子，随后Wilder平滑；持续涨为100、持续跌为0、全平为50，至少15个价格。
- MACD：EMA12/26分别用对应N个收盘的SMA初始化；DIF=EMA12−EMA26；DEA用首9个有效DIF的SMA初始化，随后EMA9；柱值=2×(DIF−DEA)。无有效种子时保持缺失。
- 成交量均线VMA5/VMA20。52周高低取最近252根日K的最高/最低，不足252根不声称完整52周。
- 最高价只称“**可用历史最高**”，覆盖区间和根数显示在详情；回撤=`(现价/可用历史最高−1)×100`，不冒称上市以来ATH。
- 主图为日K蜡烛、默认MA20/50/200，可切换八条MA；区间为1/3/6个月、1年、全部缓存。副图支持成交量（含VMA5/20）、RSI14、MACD（DIF/DEA/柱）。这不是分钟行情图，也不作交易建议。

## 暂停机制及存储

`watch_targets.alerts_enabled`有数据库 `CHECK(...=0)` 约束，自动同步只产生暂停对象。`watch_sources`保留来源，`symbol_mappings`单独保存用户覆盖，`daily_bars`/`market_state`/`indicator_cache`保存公共行情和指标。

`monitor_rules`、`alert_events`仅预留空表，P0不插入记录，没有提醒评估器、通知发送器、测试通知或后台提醒自动任务。页面切换、行情波动、更新、断网均不会启动提醒。后续P1需要用户主动配置并另行实现。
