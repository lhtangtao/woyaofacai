# 持仓管理界面

修改者：Codex（代码修改）。本次为展示层改造，沿用既有持仓、净投入、收益率及历史回放服务。

- 默认进入总览。两端采用蓝白卡片、四项可靠指标、人员/券商/股票三组汇总、独立资产分布；分布图只使用服务返回的真实金额。
- 人员与券商沿用全局双向联动。总览指标沿用当前人员及券商范围，包含历史已清仓收益；Ticker、分类、持仓状态及组合搜索作用于明细，界面有范围说明。
- 当前持仓13列，已清仓17列，顺序按产品要求保留。支持完整结果排序、展示分页、列设置、横向滚动及点击股票打开抽屉。导出完整当前匹配数据，保留既有原始数值精度。
- Web使用既有分页接口分批读全后展示分页，避免以前仅加载前200条。Python服务只补充从既有股票汇总获得的只读category字段；Web总览透传已有broker参数，没有新增计算公式或数据库字段。
- 股票抽屉宽度420–500px，摘要两列排布，保留交易记录/持仓分析/收益分析/月度表现。原有服务不提供的名称或数据不猜测填充；不新增历史成本或买卖均价算法。服务提供的历史曲线及完整性语义仍需人工核对。
- 收益颜色使用现有主题：Qt的tokens与Web的profit/loss CSS变量。本次局部样式不覆盖用户的红绿切换设置。
