# 股票归属与成本分析 V1

修改者：Codex（代码修改）。代码交付时间：北京时间 2026-10-30 09:04。

## 数据与页面

- 原入口“股票归属”使用独立的股票选择、截止日期、人员搜索、重置和 CSV 导出。不会读取或写入其他页面的人员、渠道、证券、起始日期等筛选状态。
- 通过 `AnalyticsService.calculate_people(QueryScope(..., include_disabled=True, start_date=None))` 获取全部历史人员及独立券商账本，复用 `live_holdings` 估值，不改成本、归属、拆股或成交规则。
- 共用 `services/ownership_analysis.py` 生成六张概览卡、人员及券商分层明细、成本极值、加权成本和导出。Mac 与 Web 均使用此服务。
- 持股图为横向条形，可切换股数/占比。分母始终为券商股数，不对人员占比归一化。搜索过滤人员侧概览、图表及明细，核对基准保留全部人员范围。
- 成本沿用当前持仓净投入；金额及汇总用 Decimal50，收益率使用权威成本及数量推导，不平均个股收益率。未知、无效价格和负仓保留数据状态。价格显示参考/实时来源及日期。
- 人员表严格十列；券商展开行保留七项实际字段。合计不参与排序；刷新保留展开和高亮。CSV 包含人员、券商及股数核对信息，导出文本沿用现有安全转义。
- 新页面不会调用 `ownership_choices()` 原先排除仅个人持仓的规则，股票列表保留真实全员持仓及既有持有人提示。

## 访问策略

- 本页面按用户明确授权：具有 assets:view 的桌面普通用户及管理员可读全部历史人员；移动普通用户拒绝，移动管理员放行。
- 复用现有 AuthContext、capability 和 `is_admin()`。服务端按现有 request.user_agent、Sec-CH-UA-Mobile、旧移动 UI 标识判断设备；仓库原先没有统一的设备判定函数，因此增加本页专用判断，不新建角色或 Session。
- Bootstrap 返回 `can_view_ownership`。导航隐藏、React 路由限制、主数据及导出接口、旧版报表读取/导出接口均检查。其他页面的用户人员隔离规则不变。
- 设备头是浏览器提供的信息，并非物理设备认证；桌面模式/自定义 User-Agent 的识别仍需真机验收，不宣称不可伪装设备。登录及管理员身份仍由既有服务端鉴权决定。

## 接口

扩展 `GET /api/v1/ownership`，使用本页参数：`instrument_id`、`as_of`、`person_search`；`export=csv` 下载当前局部筛选的人员及券商明细。日期默认北京时间当天，禁止未来截止日期；不使用全局 person_id、channel 等筛选。接口仅查询及估值，不改源库/表结构。

## 人工验收

1. 在其他页选择人员、渠道、股票后进入本页，确认本页仍为全人员、全渠道；返回后原筛选保持。
2. 选择股票/日期，搜索人员；核对六张概览、成本加权、横条股数/占比、十列排序及合计。
3. 展开多人券商行，等待刷新，确认展开稳定；对照当前持仓成本并检查 CSV 的局部搜索范围。
4. 使用真实异常/未知数据核对差额及价格状态，确认不补零或分摊。
5. 分别用桌面普通用户、桌面管理员、移动普通用户和移动管理员，核对导航、直接 API、旧报表及 CSV 下载；模拟移动桌面模式时单独核对设备识别边界。
