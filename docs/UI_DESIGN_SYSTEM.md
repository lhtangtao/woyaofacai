# UI重构 A–C：现代简约金融 Dashboard

本轮依据用户提供的《UI/UX全面重构开发指令》，优先交付主窗口与交易明细，不重排财务指标定义。

## 当前问题与方案

| 当前问题 | 本轮处理 |
|---|---|
| 深蓝导航与固定大标题，难以判断当前页 | 浅色分组导航、可折叠图标栏、逐页标题和说明 |
| 数据库绝对路径/快照ID长期占据顶部 | 可点击的只读状态入口；路径和技术信息集中到数据源页 |
| 多行筛选占用明细空间 | 一行常用筛选，高级条件默认收起，可清除标签与重置 |
| 只有全库待审数，缺少当前查询概况 | 同一只读查询快照计算匹配/买入/卖出/待审笔数，分账不相加 |
| JSON始终挤在表格下方 | 右侧可关闭详情抽屉，基本/账务/原始数据三个标签 |
| 表格间距、颜色和金额格式不统一 | 通用模型与轻量委托，40px行高、42px表头、Decimal显示不回写 |
| 翻页/排序同时重算全部财务报表 | 交易条件独立，分页/排序只读交易；财务页面按需加载及复用 |

## Tokens

默认浅色。背景 #F6F8FB、卡片 #FFFFFF、导航 #F0F3F8；标题 #17253D、正文 #334155、次要 #64748B、弱提示 #94A3B8。
强调 #2563EB、悬停 #1D4ED8、选中 #E7EFFF、边框 #E5EAF1；盈利 #16A34A、亏损 #DC2626、警告 #D97706。
盈利/亏损仅用于相关数值；买卖与状态用柔和标签。提供红涨/绿涨切换。深色采用同一组语义Token，不在页面私设调色板。
系统字体；页面标题24px、区域17px、计数28px、正文/表格13px、辅助12px。金融数值等宽，完整精度在提示/详情/导出中保留。
间距4/8/12/16/20/24/32；页面24、卡片16、圆角12/10/8。无渐变和厚重阴影。

## 修改文件与边界

- 新增 ui/theme.py、icons.py、sidebar.py、components.py、trade_drawer.py、workspace.py；复用现有页面、工作线程和回放服务。
- 修改 ui/main_window.py、finance_table.py、filters.py 与其他现有页面的主题入口。
- 仅在 domain/models.py、db/repositories/trades.py、services/trades_service.py 补查询条件/计数/展示元信息，不改金额计算、数据库结构或财务引擎。
- 16个原交易导出字段保留；账户/人员/费用/关联状态作为可显示附加列，人员费用无可靠分摊时显示缺失，不复制整个账户手续费。
- 撤销与参考记录可独立筛选。方向/来源/关联筛选只裁切交易列表，不用于裁掉持仓回放历史。
