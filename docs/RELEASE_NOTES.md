# 0.2.0 检查说明

1. 打开 dist/Money3.app，选择已有SQLite。
2. 默认看全部启用人员；核对原个人投资总览时，人员选择“个人”，并对齐统计日。
3. 检查首页、当前持仓、收益报表和图表；完整交易后数量/净投入在“交易回放”。
4. 异常中心输入ERROR或规则号查看来源；Excel对账页可选择原表并导出差异。

本版已具备后续阶段的可运行功能，76项测试通过；真实数据库与旧Excel仍存在财务/日期/微操差异，尚未通过等价验收。
